# PAWST CLASS 🐾

A mobile app that connects people flying from Korea to the U.S.  
with Korean rescue dogs that need a human escort to reach their forever home.

----

## Why I Built This

My dad volunteered to transport two rescue dogs — Sloane and Dabin —  
from Incheon to Atlanta in 2024. I was at the airport to see them off.

The process took weeks. Finding the right organization, understanding  
airline rules, preparing documents — all through Instagram DMs.

I thought there had to be a better way. So I built one.

----

## What PAWST CLASS Does

- Connects flight volunteers (ICN → ATL) with rescue organizations
- Matches dogs with willing travelers on the same route
- Supports foster home applications for dogs awaiting transport
- Partners with 3 verified Korean rescue organizations
- Organization dashboard with real-time volunteer matching
- Calendar view with D-day reminders including airline pet registration alerts

----

## Partner Organizations

- [K-Pups for Love](https://kpupsforlove.org/) — Atlanta, GA
- [Adopt Me Korea](https://adoptmekr.org/) — Toronto, Canada
- [Gamjane House](https://www.instagram.com/gamjane_supportlist/) — Korea
